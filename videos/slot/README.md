# Test : machine à sous avec des logos de marques (26 s)

- Composition Remotion : `SlotMachine.tsx` (style n° 1 « plat »). Elle se compose de :
  - 3 rouleaux avec un flou de mouvement vertical ;
  - le levier, les ampoules qui clignotent et le compteur de crédits ;
  - 2 parties perdues, dont un « presque » (le 3e rouleau frôle Spotify) ;
  - puis le jackpot (3 × McDonald's), avec une pluie de pièces et un compteur qui monte à 1 000 000.
- `logos/` : 16 logos au **fond transparent**, en `.svg` (vectoriel) et en `.png` (512 × 512). Ils viennent du paquet open source *simple-icons*, qui fournit les logos sous forme de tracés SVG.
- Attention : les logos restent des **marques déposées**. On peut les utiliser pour parler des marques (classements, comparaisons, actualité). En revanche, il faut éviter de faire croire à un partenariat ou de les mettre dans une vraie publicité.
